# Dashboard

Dashboard Guru menampilkan informasi absensi siswa, perizinan siswa, penilaian tugas, serta jadwal mengajar hari ini.
    <img src="/images/guru/dashboard/dash5.jpeg" alt="" style="display: block; max-width: 50%; height: auto;">


## Informasi siswa dan tugas

Dashboard menyediakan ringkasan untuk membantu guru menindaklanjuti:

- absensi siswa
- perizinan siswa
- penilaian tugas

### Menindaklanjuti perizinan siswa

1. Klik kotak informasi **Izin Menunggu**. Lalu akan tampil halaman persetujuan izin seperti berikut:
    <img src="/images/guru/dashboard/dash2.jpeg" alt="" style="display: block; max-width: 50%; height: auto;">
2. Tinjau pengajuan izin yang dikirim oleh wali murid.
3. Klik tombol <img src="/images/guru/dashboard/dash3.jpeg" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;"> untuk menyetujui pengajuan atau <img src="/images/guru/dashboard/dash4.jpeg" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;"> untuk menolaknya.
