# Input Nilai

Menu **Input Nilai** digunakan untuk memberikan nilai mata pelajaran kepada siswa.

## Mengisi dan menyimpan nilai

1. Buka menu **Input Nilai**, lalu akan tampil halaman berikut:
   <img src="/images/guru/input-nilai/i1.jpeg" alt="" style="display: block; max-width: 50%; height: auto;">
2. Pilih kelas dan mata pelajaran yang ingin dinilai.
3. Pilih jenis penilaian, seperti harian, tugas, UTS, atau praktik.
4. Masukkan nilai setiap siswa dengan mengetik nilainya pada kolom <img src="/images/guru/input-nilai/i5.jpeg" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;"> di sebelah nama siswa
5. Setelah selesai, pilih salah satu tindakan:
   - Klik tombol <img src="/images/guru/input-nilai/i3.jpeg" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;"> untuk menerbitkan nilai.
   - Klik  tombol <img src="/images/guru/input-nilai/i4.jpeg" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;"> untuk menyimpan nilai tanpa menerbitkannya. Nilai yang disimpan sebagai draf belum dapat dilihat oleh orang tua dan siswa.
