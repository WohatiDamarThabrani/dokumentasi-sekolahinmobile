# Ceklis Hafalan

Menu Ceklis Hafalan digunakan untuk mencatat setoran hafalan siswa.
    <img src="/images/guru/ceklis-hafalan/ch4.jpeg" alt="" style="display: block; max-width: 50%; height: auto;">

## Mencatat setoran

1. Buka menu **Ceklis Hafalan**.
2. Pilih surah atau doa yang disetorkan.
3. Pada baris nama setiap siswa yang menyetor, klik tombol <img src="/images/guru/ceklis-hafalan/ch1.jpeg" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;"> atau <img src="/images/guru/ceklis-hafalan/ch2.jpeg" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;"> sesuai hasil setoran.
4. Klik tombol <img src="/images/guru/ceklis-hafalan/ch3.jpeg" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;">.
