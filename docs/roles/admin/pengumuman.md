# Pengumuman

## Cara Membuat pengumuman

1. Klik ikon tiga garis horizontal <img src="/images/admin/pengumuman/p3.jpeg" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;"> di pojok kiri atas layar.
2. Pilih menu **Pengumuman**, lalu akan tampil halaman pembuatan pengumuman seperti berikut:
    <img src="/images/admin/pengumuman/p1.jpeg" alt="" style="display: block; max-width: 50%; height: auto;">
3. Tuliskan judul pengumuman.
4. Tuliskan isi pengumuman.
5. Tuliskan kategori pengumuman.
6. Jika diperlukan, klik **Tambahkan tanggal kegiatan**, lalu pilih tanggal kegiatan.
7. Pilih sasaran dan jadwal terbit pengumuman.
8. Pastikan **Kirim notifikasi** telah diaktifkan.
9. Klik tombol <img src="/images/admin/pengumuman/p2.jpeg" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;">.
