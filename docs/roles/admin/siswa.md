# Siswa

Menu Siswa berisi identitas siswa yang ada di sekolah. Jika ada siswa yang belum terdaftar di sistem, Admin dapat menambahkannya melalui fitur tambah siswa.

## Menambahkan siswa ke sistem

1. Pada menu siswa, gulir halaman ke bawah untuk menemukan tombol **+ Tambah Siswa**. Tampilannya seperti ini:
    <img src="/images/admin/siswa/s1.jpeg" alt="" style="display: block; max-width: 50%; height: auto;">
2. Klik tombol **+ Tambah Siswa**, lalu akan tampil halaman berikut:
    <img src="/images/admin/siswa/s2.jpeg" alt="" style="display: block; max-width: 50%; height: auto;">
2. Masukkan nama lengkap, email, sandi, jenis kelamin, NISN, tempat dan tanggal lahir, nomor telepon, alamat, serta catatan kesehatan.
3. Klik tombol <img src="/images/admin/siswa/s3.jpeg" alt="" style="display: inline; width: auto; height: 1.5em; vertical-align: middle; margin: 0;">.
