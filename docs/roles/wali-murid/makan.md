# Menu Makan

Menu **Makan** menampilkan daftar menu MBG selama satu pekan.

  <img src="/images/wali-murid/makan/m1.jpeg" alt="" style="display: block; max-width: 50%; height: auto;">

Wali Murid dapat memantau rincian menu dan nutrisi yang diberikan. Komposisi hidangan seperti lauk utama, lauk pelengkap, sayur, buah, dan minuman tampil disini. Informasi Gizi berupa total energi dalam kkal juga dapat dipantau oleh Wali Murid.
