# Tugas

Menu **Tugas** menampilkan tugas-tugas yang diberikan guru kepada anak.
    <img src="/images/wali-murid/tugas/t1.jpeg" alt="" style="display: block; max-width: 50%; height: auto;">

## Status tugas

Setiap tugas memiliki salah satu dari tiga status berikut:

- **Belum dikumpulkan** — tugas belum dikumpulkan.
- **Terkumpul** — tugas sudah dikumpulkan.
- **Dinilai** — tugas sudah diperiksa dan dinilai oleh guru. Nilai tugas ditampilkan pada tugas dengan status ini.

## Cara melihat detail tugas

Klik tugas untuk melihat detailnya, termasuk instruksi pengerjaan dan batas pengumpulan.
