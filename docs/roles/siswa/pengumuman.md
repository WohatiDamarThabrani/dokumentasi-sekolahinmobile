# Pengumuman

Menu **Pengumuman** berisi pengumuman yang diberikan oleh guru atau kepala sekolah.
    <img src="/images/siswa/pengumuman/p1.jpeg" alt="" style="display: block; max-width: 50%; height: auto;">

## Memilih Jenis Pengumuman

Pilih tab di bagian atas halaman untuk memfilter pengumuman berdasarkan jenis:

- Prestasi
- Libur
- Acara
- Umum
- Penting
- Akademik

Pilih tab **Semua** untuk menampilkan semua jenis pengumuman.

## Melihat Detail Pengumuman

Klik pengumuman untuk melihat isi pengumuman, nama pengirim, dan tanggal terbit.
